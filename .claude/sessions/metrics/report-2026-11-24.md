## Caveats

- Edits Frances dictates to Claude land as Claude commits, so human commits and human-edited lines are floors. Draft survival counts every change after the draft, whoever typed it.
- 5 PRs merged less than 30 days ago, so their fix counts can still grow.
- A PR whose draft is also its final commit scores 100% survival. Read survival next to the share of PRs revised after the draft: a draft polished locally before the first commit looks perfect here.
- Lag uses the latest-merged backend PR the docs PR references. An old reference inflates it, so treat it as context only.
- Fix candidates are matched on deleted lines, not intent. Check the list below before quoting the number.
- Practice effect: Frances's prompting has improved over the same months, and no PR metric separates that from the skill changes.
