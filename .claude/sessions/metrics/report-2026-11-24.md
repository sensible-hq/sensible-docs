## How to read each number

- **AI draft:** the PR's first commit that touches doc files, when Claude co-authored it. Everything after it is revision.
- **Revision lines:** lines added plus deleted on doc files in every commit after the draft, whoever made it. This is the main back-and-forth measure, because edits Frances dictates to Claude land as Claude commits.
- **Lines Frances committed herself:** doc lines in commits without a Claude co-author trailer. A floor on her hand edits: an edit she makes in her editor and Claude then commits counts as Claude's.
- **AI draft survival, words:** the share of the draft's added words that the merged PR still adds, in order. The headline survival number. A PR with no commits after the draft scores 1.0 by construction, so the revised-only row shows survival without those PRs.
- **AI draft survival, whole lines:** the share of the draft's added lines, 15 or more characters with a letter, that the merged PR still adds unchanged. One reworded word makes a line not survive. A draft spread over several commits only counts its first commit, so later additions lower the denominator, not the rate.
- **Post-merge fixes:** later PRs of 10 or fewer doc files, merged within 30 days, that delete a line this PR added. Matched on text, not intent: check the list. 5 PRs still have an open window, so their counts can grow.
- **Lag:** from the latest-merged backend PR the docs PR references. An old reference inflates it: context only.
- **Practice effect:** Frances's prompting has improved over the same months, and no PR metric separates that from the skill changes.
