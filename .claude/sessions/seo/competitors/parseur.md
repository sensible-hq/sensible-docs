Selection criteria: I prioritized getting started, AI/LLM extraction, template/OCR extraction, tables, positioning, template selection (Parseur's version of classification), splitting, file formats, validation, API auth and webhooks, and one integration (Zapier). I skipped billing/account/security FAQs, email-forwarding setup (Gmail, Outlook, Yahoo, iCloud: 7 pages), archived help pages superseded by developer.parseur.com, per-endpoint and schema pages, and near-duplicates (the field-format subtype pages, the n8n/Make/Power Automate integrations). Extraction notes: Intercom renders the article title and its main section headings as `<h1>`, and subsections as `<h2>`, so I drew phrases from all H1s and H2s. ## Patterns
- **Task-verb titles.** About 15 of 20 titles start with a verb plus an object: "Extract PDF Tables With OCR", "Split Bundled Multi-Page Documents…", "Send Extracted Data to Any Application via Zapier", "Use Field Formats to Normalize Data". Sensible titles are mostly feature nouns (Row, Region, Intersection, Sections, Fingerprint), which don't match search queries.
- **"Extract … from PDF/emails" is their core verb phrase.** It shows up in "extract text from PDF", "extract PDF tables", "extract a table from a PDF", "extract data from documents without templates", and "extract text from emails". The docs-wide grep shows Sensible's docs never use "extract PDF tables", "extract text from PDF", or "AI data extraction".
- **"Template" is their umbrella term,** in "OCR template", "template engine", "template editor", "template selection", and "multiple templates". It's the framing behind Sensible's "template-based extraction" synonym. Most of these are Parseur UI names, though, and not worth copying literally.
- **"AI engine" / "AI parsing engine" stands in for "LLM".** Parseur rarely says LLM in headings. Sensible says "LLM" throughout, and that's a gap for searchers who type "AI" (for example, "AI data extraction" or "parse documents using AI").
- **FAQ-style H2s target long-tail questions:** "Can Parseur Extract Data from Password-Protected PDFs?", "What Is the Maximum Document Size…", "How can I parse checkboxes or radio buttons?", "Can the AI extract data from long documents?". This is good GEO bait, since AI search engines quote Q&A headings, and Sensible has almost no question-form headings.
- **Many borrowables are Parseur product vocabulary,** for example field constraints, field instructions, dynamic OCR, AI vision engine, and template editor. Ignore those. The useful ones are generic task phrases about tables, splitting, and file limits.
