# Knowledge

Verified facts about how Sensible behaves, for writing and reviewing docs. This differs from `.claude/style-guide/`, which covers how to write.

Each file states the rule, says how it was verified (backend code, a test-account run, or the app), and records misconceptions that have come up, so they don't come up again. Docs, fixtures, and PRs can link here as the source for a claim.
