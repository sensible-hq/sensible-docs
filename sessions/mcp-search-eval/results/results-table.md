## How the pipeline works

1. Agent calls `mcp__sensible-docs__search` → MCP returns a list of `{id, title, url}` results
2. Agent calls `mcp__sensible-docs__fetch` on each result ID → MCP returns raw doc text
3. Agent (Claude) reads the fetched text and synthesizes an answer

**"Docs returned by MCP"** = verbatim titles + URLs from the MCP `fetch` calls, as recorded in the raw JSON artifacts. Where marked *raw data incomplete*, the agent did not save fetched page metadata.

**"LLM-synthesized answer"** = Claude's interpretation of the fetched doc content only. No prior knowledge used.
