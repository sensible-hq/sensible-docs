# Q: What file types can I upload?

## Answer

Sensible supports the following file types for document upload and extraction:

- **PDF**
- **Microsoft Word** — DOC and DOCX
- **Spreadsheet formats** — XLSX, XLS, XLSM, and CSV
- **Single-page image formats** — JPEG, PNG
- **Multi-page image formats** — TIFF

### Context-dependent support

Not all file types work in every context. Key limitations:

- **TIFF** is not supported in the Sensible app's Extract tab, portfolio extraction, or email bodies — only via SDK/API single-file extraction, email attachments, and classification.
- **Spreadsheet formats** do not support portfolio extraction.
- **JPEG/PNG** support portfolio extraction only for single-page images (Sensible returns the first document identified in the file).

### SenseML method limitations

- **Spreadsheets** do not support pixel-rendering methods (Box, Checkbox, etc.), NLP/Fixed Table methods, or OCR. Text is extracted directly.
- **TIFF** supports only OCR-based text extraction — no pixel-rendering methods or table methods.

### File size limits

| Operation | Synchronous limit | Asynchronous limit |
|---|---|---|
| Single-document extraction | Under 4.5 MB or 30 seconds processing | 6 GB |
| Portfolio extraction | n/a | 6 GB |
| Classification | 4.5 MB | 4.5 MB |

### File conversions

- Word documents and email bodies are converted to PDF before processing.
- Spreadsheets bypass OCR entirely; Sensible standardizes cell dimensions (0.25" tall, 1" wide) and splits sheets taller than 15 inches into consecutive pages.
