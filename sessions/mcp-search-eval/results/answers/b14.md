# Question
How do I handle a single PDF that contains multiple different documents?

# Answer

Sensible calls a single file containing multiple documents a **portfolio**. It can segment each sub-document by its page range and return extracted data from each document separately.

## Recommended approach

Use a separate Sensible document type for each kind of document in the portfolio (e.g., an `income_tax` type and an `invoice` type), rather than creating one combined type. This lets you write independent validations per document type.

## Two segmentation methods

**LLM-based segmentation**
- In each document type's **Settings** tab, write a description of that document type in the **Description** field.
- Sensible uses that description to prompt an LLM to identify which pages belong to which document type.
- Granularity: at the document-type level.

**Text-based segmentation ("fingerprints")**
- Add a `fingerprint` block to each config that will appear in the portfolio. Fingerprints specify text strings to match on first pages, last pages, or other page positions.
- Sensible uses these matches to identify page boundaries.
- Granularity: at the config level (finer than LLM mode).

## How to run a portfolio extraction

**Sensible app:**
1. Upload the file on the **Extract** tab.
2. Click **Portfolio**, choose **LLM mode** or **fingerprint mode**.
3. Select the document types the portfolio contains.
4. Click **Extract**.

**API:**
```json
curl --location 'https://api.sensible.so/v0/extract_from_url?environment=production&document_name=my_portfolio' \
--header 'Content-Type: application/json' \
--header 'Authorization: ••••••' \
--data '{
    "document_url": "https://example.com/my_portfolio.pdf",
    "types": ["bank_statements", "pay_stubs", "1040s"],
    "segment_documents_with": "llm"
}'
```

For fingerprint mode (asynchronous, two-step):
1. POST to `extract_from_url` with the `types` array (fingerprints already configured in configs).
2. GET the result using the returned extraction ID from `https://api.sensible.so/v0/documents/{id}`.

The response includes a `documents` array where each entry has `documentType`, `configuration`, `startPage`, `endPage`, and `output`.

## Limitations
- Each sub-document must start at the **top of a page**; mid-page document starts are not supported.
- Supported file types are listed in the Sensible "Supported file types" docs page.
