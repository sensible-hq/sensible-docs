# b03 — Extract a specific field from a PDF

## Question

How do I pull out a specific field from a PDF?

## Answer

Based on the fetched docs, the way to extract a specific field from a PDF in Sensible is:

1. **Write a field query in SenseML.** A field is the basic unit of extraction. Each field produces a JSON key-value pair in the output. A minimal field has three required parts:
   - `id` — the key name in the output JSON.
   - `anchor` — text in the PDF that locates the data you want (required for layout-based methods).
   - `method` — how to expand from the anchor and grab the target value (e.g., `"id": "box"` to return all text inside a bounding box containing the anchor text).

   Example from the docs:
   ```json
   {
     "fields": [
       {
         "anchor": "rents",
         "id": "rents_income",
         "method": {
           "id": "box"
         }
       }
     ]
   }
   ```
   Output:
   ```json
   {
     "rents_income": {
       "type": "string",
       "value": "$ 4,200"
     }
   }
   ```

2. **Choose a method.** SenseML supports layout-based methods (spatial rules using anchors) and LLM-based methods (e.g., `queryGroup`, which uses natural language to describe what to extract). The SenseML reference introduction mentions both.

3. **Optionally add a `type`** to coerce the output to a specific data type (e.g., currency, address, or a custom type).

4. **Call the API to run the extraction.** The API reference page lists synchronous and asynchronous endpoints. Use the synchronous endpoint for testing and the asynchronous endpoints in production.

The field query object page (https://docs.sensible.so/docs/field-query-object) is the primary reference for field structure.
