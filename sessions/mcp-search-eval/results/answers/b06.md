# b06 — What does the output actually look like?

## Question

What does the output actually look like?

## Answer

Based on the fetched pages, Sensible returns extracted document data as a JSON object. The top-level structure has a `parsed_document` key, and each extracted field appears as a nested JSON key-value pair.

**Simple string field** — the most basic output shape:

```json
{
  "parsed_document": {
    "your_first_extracted_field": {
      "type": "string",
      "value": "Welcome to your first document"
    }
  }
}
```

Every extracted value is an object with at minimum a `type` and a `value` property.

**Currency field** — adds `source` and `unit` properties:

```json
{
  "quote_rate": {
    "source": "$800",
    "value": 800,
    "unit": "$",
    "type": "currency"
  }
}
```

**Table field** — produces a `columns` array, where each column has an `id` and a `values` array of typed value objects. Tables may also include a `title` object:

```json
{
  "overview_table": {
    "columns": [
      {
        "id": "attribute",
        "values": [
          { "value": "key concepts", "type": "string" },
          { "value": "key method categories", "type": "string" }
        ]
      },
      {
        "id": "description",
        "values": [
          { "value": "Fields, anchors, and methods", "type": "string" },
          { "value": "LLM-based, layout-based, and computed", "type": "string" }
        ]
      }
    ],
    "title": {
      "type": "string",
      "value": "SenseML overview"
    }
  }
}
```

**Null fields** — when a field is not found, it returns `null`:

```json
{
  "broker.email": null
}
```

**Validations** — if the config includes validations, the response also contains a `validations` array and a `validation_summary` object alongside `parsed_document`:

```json
{
  "validations": [
    {
      "description": "The zip code is valid for USA or CA",
      "severity": "warning"
    },
    {
      "description": "Broker's email is in string@string format",
      "severity": "skipped",
      "message": "Missing prerequisites: broker.email"
    }
  ],
  "validation_summary": {
    "fields": 5,
    "fields_present": 4,
    "errors": 0,
    "warnings": 1,
    "skipped": 1
  }
}
```

In summary: the output is a `parsed_document` object where each key is a field ID and each value is a typed JSON object (or `null`). The exact shape of the value depends on the field type — strings and numbers are flat `{type, value}` objects; currencies add `source` and `unit`; tables are nested arrays of column objects.
