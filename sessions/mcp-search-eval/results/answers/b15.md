# Question
How do I know if my extraction is accurate?

# Answer

Sensible provides four ways to measure extraction accuracy:

1. **Logical validations** — Write rules in JsonLogic to check that extracted fields meet your conditions. For example, return errors if a quoted rate is null, a broker's email isn't in `string@string` format, or a zip code has more than 5 digits. See the "Validate extractions" docs for details.

2. **OCR confidence scores** — Get a quality score for text images (e.g., scanned or photographed documents). This flags text that is blurry or illegible. Also covered in "Validate extractions."

3. **Confidence signals** — For LLM-extracted data, Sensible asks the LLM to report uncertainties about its output. For example, an LLM can flag that it found multiple answer candidates. See "Qualifying LLM accuracy" for details.

4. **Extraction coverage** — A percentage score measuring how fully an extraction captured all data in a document. It compares non-null, validated fields to total fields returned by a config. A coverage score of 70% with no validation errors means 30% of fields were null. See "Monitoring extraction metrics" for details.

Source: [Accuracy measures](https://docs.sensible.so/docs/accuracy-measures)
