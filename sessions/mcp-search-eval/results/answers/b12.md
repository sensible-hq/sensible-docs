# Question
Is there a way to try it without setting up API calls?

# Answer

Yes. Sensible provides two no-code ways to try extraction in the browser without writing any API calls.

## 1. Quick extraction tab (Extract UI)

The Sensible app has an **Extract** tab at [app.sensible.so/quick-extraction/](https://app.sensible.so/quick-extraction/) that lets you upload a document and run an extraction entirely in the browser:

1. Go to the **Extract** tab.
2. Select **Document** (single file) or **Portfolio** (multi-document bundle).
3. Pick a **Document type** from the dropdown. If you haven't set up your own, choose `llm_basics / Auto select` — this document type includes pre-built examples for bank statements, resumes, and contracts, and Sensible will automatically pick the best config for whatever you upload.
4. Click **Upload document**, then **Run Extraction**.
5. Extracted data appears as JSON in the right pane. You can also **Download Excel** to get the results as a spreadsheet.

A sample document (bank statement) is provided if you don't have one handy: [bank_3.pdf](https://raw.githubusercontent.com/sensible-hq/sensible-docs/v0/assets/pdfs/bank_3.pdf).

## 2. Template library + visual editor

From the **Template library** tab in the Sensible app, you can browse and clone pre-built extraction configs for dozens of common document types (bank statements, pay stubs, tax forms, insurance policies, resumes, etc.) with one click. After cloning, you can open the config in the visual editor to inspect the extraction logic against a sample document, with extracted data shown in a side pane — no API calls required.

The API quickstart page also notes that after running an API call you can optionally view the same extraction in the visual editor (config in left pane, document in middle pane, results in right pane), which works as a standalone browser-based exploration tool as well.

## What requires an API key

Calling the extraction API programmatically (e.g., via curl, SDK, or your own app) does require an API key. But the in-app UI tools above do not require you to construct or send API requests manually.
