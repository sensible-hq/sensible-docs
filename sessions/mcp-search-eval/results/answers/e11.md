# e11

## Question

Can dynamic external ranges in sections search backwards (preceding each section start) and if so, how does `reverse: true` on the anchor interact with `anchorIsAbsolute`?

## Answer

Yes, dynamic external ranges can search backwards (i.e., in lines that precede each section start).

By default, when `anchorIsAbsolute` is `false`, Sensible creates dynamic external ranges relative to each section start and **searches forward** — in the lines succeeding the start of each section. To search in the opposite direction (lines that precede the section start), you set `"reverse": true` on the external range's `anchor`. The docs describe this explicitly:

> "Sensible starts searching for dynamic external ranges in the lines succeeding the start of each section. To search for dynamic external ranges that precede each section, use `"reverse":"true"` on the external range's anchor."

The working relationship between `reverse: true` and `anchorIsAbsolute` is:

- `reverse: true` only applies when `anchorIsAbsolute` is `false` (the dynamic case). It tells Sensible to search backwards from each section start to find the closest match for the external range anchor, rather than searching forward.
- When `anchorIsAbsolute` is `true`, Sensible creates **one static external range** by searching from the start of the document. In this mode, there is no per-section search direction to reverse — `reverse: true` is irrelevant.

The dynamic example in the docs demonstrates this directly. Page headings ("Claim contents") appear above (preceding) each section. Because `anchorIsAbsolute: false` and `reverse: true` are set together, Sensible searches backwards from each section's start line to find the nearest "Claim contents" heading, producing a per-section dynamic external range that tracks the correct (and variably-positioned) page heading for each claim.
