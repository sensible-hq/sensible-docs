# b02 — Do I need to write code to use this?

## Question

Do I need to write code to use this?

## Answer

No, you do not need to write code to use Sensible. The docs describe multiple no-code and low-code options alongside the API and SDKs.

**No-code options:**

- **Quick extraction UI** — Drag and drop documents directly in the Sensible app to extract data without writing any code. You can upload files in bulk and download extracted data as JSON or Excel files.
- **Zapier integration** — Connect Sensible to emails, databases, Google Sheets, and other destinations through Zapier without writing code.
- **Email extraction** — Forward email bodies and attachments to a Sensible email alias to trigger extraction automatically.

**Authoring configs** — Even when you're building extraction configs, the Getting Started guide shows you can write natural-language prompts (e.g., "what's the customer service number?") directly in the Sensible app UI. No code is required to author or publish a config.

**Code-required options (for developers):**

- **API** — REST endpoints for extracting and classifying documents programmatically.
- **SDKs** — Libraries for extracting and classifying documents in code.
- **MCP server** — For AI-powered code editors like Claude Code or Cursor.

The platform describes itself as "developer-first" and the overview page positions API/SDK integration as the primary use case for building document-automation features into SaaS products. But the quick extraction UI, Zapier, and email integrations are genuine no-code paths for users who don't want to write code.
