# Q: Can it detect whether a checkbox is checked?

## Answer

Yes. Sensible has two dedicated methods for detecting checkbox state, both returning a boolean (`true` for selected, `false` for unselected).

**Checkbox method** (`"id": "checkbox"`)

Searches horizontally from an anchor for a nearby checkbox. It uses two detection strategies in order:

1. **PDF form metadata** — if the PDF contains embedded checkbox form data, Sensible uses that preferentially.
2. **Pixel recognition fallback** — if no metadata exists, Sensible analyzes pixel darkness within the checkbox bounds. A box with more than 5% darkened pixels is considered checked. Default supported size is up to a 0.3-inch square.

Key parameters for tricky cases:
- `offsetX` / `offsetY` — shift the search point inside the checkbox for non-standard layouts.
- `width` / `height` — define the detection region explicitly for large or borderless checkboxes.
- `darknessThreshold` — tune sensitivity for checkboxes on dark or scanned backgrounds.
- `ignoreFormData` — bypass metadata and force pixel recognition (useful when a PDF editor embedded bad form data).

Example output:
```json
{"checkbox_left": {"type": "boolean", "value": true}}
```

**Nearest Checkbox method** (`"id": "nearestCheckbox"`)

Searches in all directions from the anchor for the nearest checkbox. It also uses metadata first, then falls back to OCR and machine learning rather than pixel rules. This makes it more flexible and able to handle a wider range of checkbox formats (including ones without clear borders), but it is slower than the basic Checkbox method because it uses OCR.

Key parameters:
- `position` (required) — `left` or `right`, sets the starting search point.
- `offsetX` / `offsetY` — further shift the starting point.
- `maxYDistance` — cap the vertical search range, useful for tightly spaced rows of checkboxes.
- `ignoreFormData` — same bypass behavior as above.

Example output:
```json
{"checkbox_right": {"type": "boolean", "value": true}, "checkbox_below": {"type": "boolean", "value": false}}
```

**Which to use:** Use the Checkbox method when you know the checkbox position relative to the anchor and want speed. Use Nearest Checkbox when checkbox formats are varied or position is unpredictable.
