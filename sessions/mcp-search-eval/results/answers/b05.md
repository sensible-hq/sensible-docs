# b05 — Can Sensible handle scanned documents or photos of documents?

## Question

Can Sensible handle scanned documents or photos of documents?

## Answer

Yes, Sensible handles scanned documents and photos of documents. Here is how, based on the fetched documentation:

**Automatic OCR for scanned PDFs and images**

Sensible automatically performs OCR on documents that lack embedded text. The processing pipeline works as follows:

1. Sensible converts supported file types to PDF.
2. For documents with embedded text (digital PDFs), it extracts text directly.
3. For documents without embedded text, it determines whether OCR is needed:
   - Image files (e.g., PNG) always trigger whole-document OCR.
   - For PDFs, Sensible uses heuristics to decide if OCR is needed (configurable via the OCR Level parameter).
4. An OCR preprocessor can be applied to specific pages or page ranges even when whole-document OCR was not triggered.

**Configurable OCR options**

Three parameters let you control OCR behavior:

| Option | Scope | Purpose |
|---|---|---|
| OCR Level | Document type | Criteria for triggering whole-document OCR |
| OCR preprocessor | Config | OCR specific pages or page ranges |
| OCR Engine | Document type | Choose OCR provider (Amazon, Google, or Microsoft) |

**Handwriting**

For handwritten text, the docs recommend:

- Use **Google OCR** engine (configured via the gear icon on the Document Type).
- Define a region with a small height and long width running through the middle of the handwriting area, because handwriting can occupy unpredictable regions or overlap other lines.
- Use the **Sort Lines parameter** to correct vertical misalignment (jitter) common in handwritten text.

**Photos and non-text images**

For photographs, charts, or illustrations (i.e., non-text visual content), OCR alone is insufficient. The docs point to the **Query Group method's Multimodal Engine parameter** as the appropriate tool. The Multimodal Engine can also be used as an alternative to OCR for poor-quality text images, such as handwriting.

**Confidence scores and quality monitoring**

Sensible provides confidence scores for OCR'd text when high verbosity is configured, so low-quality scan results can be identified. The docs recommend writing validations to warn about extractions from low-quality scans.
