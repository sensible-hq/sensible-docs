## Question
When a portfolio uses LLM segmentation and a document spans pages that start mid-page, how does Sensible fail — silent drop, error, or partial extraction?

## Answer

The docs don't describe a runtime failure mode (no mention of a silent drop, an error response, or partial extraction output). Instead, the limitation is stated as an unsupported configuration: Sensible simply does not support segmenting a document that starts mid-page in a portfolio. The docs state flatly:

> "Sensible doesn't support segmenting a document that start mid-page in a portfolio. It expects that the first page of each document in a portfolio starts at the top of a page."

This constraint applies to portfolio segmentation generally (it appears in a "Limitations" section without distinguishing LLM mode from fingerprint mode). The docs give no information about what actually happens at runtime if this requirement is violated — they only say the scenario is unsupported.

**Source:** [Multi-document extractions](https://docs.sensible.so/docs/portfolio)
