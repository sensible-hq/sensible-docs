# Style rule hierarchy

Generated by `python3 scripts/style/rule_map.py hierarchy` from `registry.yaml`, the Jev specs in `judgment/`, and `.vale.ini`. Don't edit it by hand; `check_registry.py` fails when it's stale.

64 registered rules: 11 general, 7 page-type, 46 construct. Enforced by: 16 Jev, 20 Vale, 1 manual, 29 prose, 5 script. Plus 33 Google package rules that run on every page, and 26 rule-like sentences in the guides with no registry entry (`rule_map.py coverage`).

Enforcement: **Vale** matches a pattern; **Jev** judges each candidate a detector finds (trusted rules can fail a run, advisory rules only report); **script** is a repo check; **manual** is a judgment a person applies; **prose** means the guide is the only carrier.
