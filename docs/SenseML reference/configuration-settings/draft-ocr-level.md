The OCR level for a given document type is the minimum OCR level amongst its configurations.

| Possible Values | Description                                                              |
| :-------------- | :----------------------------------------------------------------------- |
| `0`             | disable OCR                                                              |
| `2`             | default, automatic OCR when the engine detects that OCR may be necessary |
